# RhythmGAYme

自分の曲ファイルで遊ぶ、ブラウザ用4レーン音ゲー。

## 遊び方

1. このページを開く（GitHub Pages 公開後はそのURL）
2. 曲ファイル（MP3 / OGG / WAV / M4A）を選ぶか、ドラッグ&ドロップ
3. 難易度とノーツ速度を選んでスタート

- キー: **D / F / J / K**
- スマホ: レーンをタップ
- Esc / ポーズボタン: 一時停止
- 判定: PERFECT / GREAT / GOOD / MISS、コンボ・スコア・精度・ランク（S〜D）

選んだ曲ファイルは**端末の中だけで読み込まれ、サーバーやGitHubには送信されません**。
譜面は曲の音の立ち上がりを解析して自動生成します。判定が合わないときは
「判定ずれ調整 (ms)」で合わせてください。

## リポジトリに曲を入れる場合

`songs/` フォルダに音声ファイルを置き、`songs/index.json` に
`[{"title":"曲名","file":"ファイル名.mp3"}]` の形で書くと、
トップ画面に収録曲ボタンが出ます。

⚠️ **注意（ライセンス）**: このリポジトリは Public です。音声ファイルを置くのは
「音源の再配布」に当たるため、**CC0など再配布が許可された曲だけ**を入れてください。
DOVA-SYNDROME（OpenTracks）や魔王魂、Pixabay Music などのフリー音源は
再配布禁止のものが多く、そのままコミットすると規約違反になります。
そうした曲で遊びたいときは、上の「ファイルを選ぶ」から端末上で読み込んでください
（ファイルは公開されません）。

## 専用譜面: Sky High

`charts/sky-high.json` に **Elektronomia — Sky High [NCS Release]** の専用譜面が入っています。
ゲームでこの曲のMP3ファイルを選ぶと、ファイル名／曲の長さで自動マッチして専用譜面で遊べます。

- BPM 128（実ファイル解析で拍オフセット 0.240s に合わせ込み）、長さ 236.3s
- ノーツ数: EASY 273 / NORMAL 505 / HARD 824

> Song: Elektronomia - Sky High [NCS Release]
> Music provided by NoCopyrightSounds
> Free Download/Stream: https://ncs.io/skyhigh

⚠️ 音声ファイル自体は**リポジトリに入っていません**。NCSの利用ポリシーでは、
ゲームへの組み込みは商用利用として別途 Commercial License が必要で、
音源の再配布も許可されていません。各自が持っているファイルを端末上で
読み込んで遊ぶ形にしています（公開して遊ばせる場合はNCSへのライセンス申請が必要です）。

### 譜面制作ノウハウ（この譜面の作り方）

調べた作譜の定石をそのまま適用しています:

1. **音取りを決める**: どの音にノーツを合わせるか先に決める（この曲はキック/スネア中心の拍）
2. **拍グリッドに合わせる**: オンセット検出（エネルギー増加＝スペクトルフラックス）で
   立ち上がりを拾い、BPMの拍グリッドにスナップしてズレをなくす
3. **難易度は「強度」で作り分ける**: 全オンセットをノーツにせず、周囲平均に対する
   突出度が高いものから残す。密度の目安は EASY 約1.3 / NORMAL 約2.4 / HARD 約3.7 ノーツ/秒
4. **緩急をつける**: 小節ごとの音量で密度を変える（静かな所は薄く、ドロップは濃く）。
   最初から最後まで全速力にしない
5. **同時押しは最大2つ**（スマホの親指2本で押せる範囲）、強い小節頭だけに置く
6. **同じレーンの連続は最大2回**まで。レーン決定はシード固定乱数で、
   誰が遊んでも・何回遊んでも同じ譜面になる
7. **判定ずれ調整**（オフセット設定）を必ず用意する

## 構成

- `index.html` — ゲーム本体（1ファイル完結、ライブラリなし）
- `charts/sky-high.json` — Sky High専用譜面（音声は含まない）
- `songs/` — リポジトリ収録曲の置き場（任意）

## 開発メモ

  難易度ごとの最小間隔・しきい値でノーツ化。HARD は強いピークで同時押しあり。
